# Assets Directory 🌌

Central storage for all multimedia assets, visual graphics, sound files, and distribution archives.

## 🗂️ Organization

```
assets/
├── archives/          # Packaged build releases, zip archives, and distributables
│   └── voyager-game.zip
├── audio/             # Sound effects, ambient space tracks, and synthesizer presets
│   └── README.md
├── images/            # Logos, vector icons, UI textures, badges, and social banners
│   └── voyager-logo.svg
└── README.md          # Asset directory documentation
```

## 📐 Guidelines
- **Vector Artwork**: Store icons, UI badges, and logos in `.svg` format for crisp scaling across Retina and 4K displays.
- **Audio Files**: Use `.ogg` or `.mp3` format with high compression efficiency to keep download times minimal.
- **Archives**: Keep production release zips and offline bundles inside `archives/` instead of cluttering the root folder.
